# 原生设置交互改版

2026-11-04 · VoBLE 工作树 · 对应 [交互方案](README.md)

## 实现结构

首页保留纯本地滑块、当前设备摘要和六个分类：连接与设备、来电与短信、灵动岛与小组件、外观与偏好、帮助与诊断、关于 AirSIM。

使用 SwiftUI `NavigationStack`、类型化路由、系统分组 Form、系统返回、可滚动输入和语义颜色。玻璃只用于原有纯本地滑轨及系统导航控件；支持旧系统材质回退和减少透明度。列表不铺玻璃，文字使用动态字体。设置表单在 iOS 26 及以上使用原生 `scrollEdgeEffectStyle(.soft, for: .top)`，让滚动内容在顶部柔和模糊、淡出；iOS 27.2 同样使用这一公共接口，旧系统保留原生默认行为。

`AirSIMSettingsView` 统一持有表单草稿和诊断任务；切换详情页不会重建整个设置模型，也不会因首页消失取消自检。已完成结果保留，只有离开设置、改变 Relay 或切换纯本地策略时取消相关任务。

## 原型到原生的对应

| 原型旅程 | 原生入口与实现 |
| --- | --- |
| 日常设置 | 首页 → 六个分类，常用开关在分类首屏 |
| 首次配对 | 连接与设备 → 添加设备 → 自动发现；复用真实发现、一次性码及结果流程 |
| 手动 IP / VPN | 添加设备 → 手动地址配对，预选正确方法；网络教程与特殊网段单独成页 |
| 蓝牙配对 | 添加设备 / 蓝牙连接 → 蓝牙配对；真实安全码与认证状态继续由现有配对页展示 |
| 纯本地 | 首页滑块 + 独立说明；通话期间锁定；本机阻断与安卓同步状态不混为一谈 |
| 云端检查 | 帮助与诊断 / Relay → 云端连接自检；不受通话偏好限制，受纯本地限制 |
| 公网 TLS | 域名首次配对与已配对域名配置分开；教程、试验性标记、证书及身份校验保留 |
| 通知转发 | 来电与短信 → 通知转发 → 目标编辑 → 消息模板；模板共享未保存草稿，取消需确认 |
| 小组件 / 灵动岛 | 显示开关、排序、桌面教程、系统时限说明分开；排序不切换通话设备 |
| 反馈 | 帮助与诊断 → 提交反馈 → 上传范围；文字持久保存，手动上传，纯本地在采集前拦截 |
| 设备管理 | 设备列表 → 详情 → 地址与配对信息；删除需确认，通话中不可忘记设备 |
| 版本更新 | 关于 → 原有更新说明 / 版本检查；继续使用现有延迟呈现与渠道策略 |

原型的 44 个展示页并非 44 个独立服务器接口。配对结果、安全码、日志条目、更新结果和模板等子步骤继续呈现在既有任务页面或系统面板内；避免多余跳转与重复网络请求。

## 图标细节

纯本地滑块的左右箭头与忙碌指示使用白色。根据后续反馈，设置分类及子页导航图标恢复无底框的蓝色线性样式；纯本地标题原有图标底框保留。Tab 图标在此前大小上再放大 10%，标签栏始终展开，不再随上下滚动收缩。

## 行为约束

- 本地检查只探测已配对的控制网关。蓝牙页展示真实认证、队列与媒体状态；两者均不宣称完成双向音频验收。
- 模式选择同时检查纯本地约束、活动通话、远端通话和待拨号状态。选择模式不会伪造连接成功。
- Relay 输入先验证完整 URL。无效输入保留，不会静默改成维护者服务器。兼容已有 HTTP 自托管地址；推荐 HTTPS。
- 修改 Relay 后清除旧自检结果；保存地址不等于注册成功。
- 通知权限读取 iOS 实际值；本地网络与蓝牙不提供伪造的授权结论，而是给出系统设置入口。
- 反馈“上传范围”明确是字段类别和用户文字预览，不声称是完整上传载荷或已彻底脱敏的原始 TXT。
- 通知转发配置依旧在下次加密配对时同步到安卓。没有新增静默上传或测试短信。
- TLS 教程支持作为导航详情或独立 sheet；避免在设置详情里嵌套第二个导航栈。

## 设计依据

- `apple-design / settings.md`：不常用的设置分组，按任务逐步披露。
- `apple-design / layout.md、accessibility.md`：使用系统布局、动态字体、带文字状态，保持功能在紧凑与宽屏可达。
- `apple-design-os`：系统导航、分组 Form、明确返回、44 点触控区域、聚焦任务的 sheet。
- `liquid-glass-design`：玻璃用于控件层，多个玻璃元素位于 `GlassEffectContainer`；降低透明度时提供实体回退。
