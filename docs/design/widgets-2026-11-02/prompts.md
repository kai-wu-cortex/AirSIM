# AirSIM Widget 概念图提示词

使用内置 imagegen；接口不支持指定或核验 image2.5 版本。图片用于方向讨论，不是最终 WidgetKit 布局。全系列范围：systemSmall、systemMedium、systemLarge、systemExtraLarge（iPad）及 accessoryCircular、accessoryRectangular、accessoryInline。

落地约束：以系统实际尺寸为准；锁屏遵循系统单色/着色渲染；概念图中的彩色锁屏图标和示意比例不作为实现规格。状态来自带时间戳的快照，过期使用“状态待刷新”，不能由实时活动结束推断设备离线。拨号和短信入口打开 App，不以点击图片控件直接发起真实通话。桌面 Widget 与 Live Activity 分开实现。

## native

Use case: ui-mockup. Create a highly polished Apple platform widget concept design presentation for AirSIM, a companion app connecting iPhone to an Android SIM phone via VoWLAN, VoBLE or cloud. This is a DESIGN CONCEPT, not an app screenshot. Render a tall 4:5 board with excellent typography, generous margins, readable simplified Chinese, precision alignment and professional product design. No phone device frames. Brand mark is a WHITE rounded square containing a BLUE GRADIENT classic phone handset (not airplane, not SIM card). Show one cohesive full widget family in a carefully spaced grid, each labelled outside the widget: 小号 (square), 中号 (wide 2:1), 大号 (square twice small size), 超大号 · iPad (wide 2:1), 锁屏 (three samples: circular, rectangular, inline). All six families must be present, none cut off. Large and extra large show useful information hierarchy, not merely enlarged small widget. Small: device name 'Galaxy', 'VoWLAN', '最近在线', tiny '更新于 08:42'. Medium: same with battery '82%' and '打开 AirSIM' action. Large: 设备状态, 'Galaxy · 最近在线', connection type, battery, '打开拨号', '查看短信', concise recent activity with masked number '138 •••• 6028'. Extra large: two Android device columns 'Galaxy' and 'Redmi', latter says '状态待刷新' and '更新于 昨晚 23:10' with neutral gray not red, useful quick actions and recent calls. Lock screen uses monochrome symbols, concise text 'Galaxy · 08:42 更新', not tiny dense dashboard. Show explicit timestamps in all desktop widgets so cached data is never misrepresented as real time. No fake always-on claims, no eight-hour countdown, no graphs invented for decorative telemetry, no relay URLs or developer text. Footer small Chinese text '概念设计 · 状态以最近一次更新为准'. Text must be accurately typeset, crisp and restrained. Direction 01: 系统原生. Header 'AirSIM' then '01 / 系统原生'. Warm off-white board, solid white and very pale system-gray widget surfaces, almost invisible shadows, generous Apple-native rounded corners, SF-like Chinese typography, confident dark navy headings and restrained system-blue actions, green used only for recent connectivity. Focus on clarity and calm, no gradients except the tiny phone brand icon. Editorial design spec board, clean front-on 2D UI, spacious and highly legible.
