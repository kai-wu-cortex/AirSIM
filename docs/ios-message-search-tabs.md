# 短信搜索与标签栏交互

2026-11-04，VoBLE 工作树。

## 行为

- 短信列表增加搜索栏，检索本机已同步短信的联系人姓名、号码及所有短信正文。号码检索兼容空格、连字符及全角数字。
- 命中旧短信时显示最近一条匹配短信的摘要和时间；进入后仍是完整会话。清空搜索恢复完整列表，搜索不会标记已读或触发服务器查询。
- 搜索条件变化时清空批量删除选择，避免删除已经隐藏的会话；删除会话仍沿用原有整段会话删除规则。
- 五个底部标签使用线性 SF Symbols，选中态保持轮廓图标，原有未读角标保留。图标使用小号 symbol，当前为 20.57 pt（在此前 18.7 pt 基础上再放大 10%）；标题与系统点击区域不缩放。
- 标签栏始终展开。iOS 26 及以上明确使用 `.tabBarMinimizeBehavior(.never)`，移除上下滚动引起的收缩／展开监听、状态和旧阈值策略；旧系统保持普通标签栏。短信详情页和通话界面的原有隐藏行为保留。
