# AirSIM Apps v0.9.8.26 — 通话界面、多卡信号与稳定性

2026-11-21（Asia/Shanghai），基于 develop。Android Standalone／AVF Bridge **0.9.8.26（141）**；iPhone／Watch／Widget／短信通知扩展 **0.9.8（185）**。

## 更新内容

- 更新拨号页的大圆按键、最近通话列表与蓝灰通话界面。通话中可收起界面并返回；保留现有通话、选卡、连接和音频控制逻辑。
- iPhone 和 Watch 在 PushKit 回调中及时上报 CallKit，补齐无效／过期推送的系统收尾与仅一次 completion，避免结束另一通电话；修复已确认的未处理 VoIP 推送崩溃路径。
- Root 短信使用 App 持有的逐段系统发送回执。只有确认未发送时才允许安全回退；发送结果未知时停止重试。补齐多用户和系统接口兼容，保留 140 版 Shizuku 回执修复。
- 修复云端 SIM 列表及拨号／短信命令入口对安卓三行 PhoneAccount 标识的兼容；仍严格校验格式和长度。自检补充所选 SIM 确认状态。
- 修复云端呼出状态处理，避免把呼出接通当作来电接听命令；保留命令去重与通话身份校验。
- 灵动岛与桌面小组件显示各张 SIM 的信号，需要新版安卓上报；无可靠采样、旧端或过期数据显示未知，不猜测信号或影响在线判定。
- 手机与手表短信列表增加精确号码匹配的服务号码图标，联系人照片优先；资源说明见 [SMSCarrierIcons](../SMSCarrierIcons.md)。
- 开屏加入“拨号与通话界面”“多卡信号与稳定性”两组本地 SVG 介绍；保留减少动态效果设置。Android 更新说明同步。

## 升级与验收边界

- Android 正式包沿用原发行证书；Debug 安装不能直接覆盖为正式包，不建议卸载丢失配对数据。
- 公开 full／sideload IPA 是未签名包，需自行签署主 App 和全部扩展；full 包含 Watch，sideload 不含 Watch。TestFlight 使用独立 App Store 签名上传。
- 本次同步 Cloudflare 与阿里云 ECS 的 AirSIM Relay；不修改同机的 AirSIM Cloud／TURN，不更新独立 AVF Linux Agent 或 U30Air 固件。
- 系统发送成功不等于对方收到；其他厂商、多段短信和更多 Root 环境仍需实测。历史缺失的发信记录不会自动补回。
- 已确认的 PushKit 崩溃路径修复不代表所有 TestFlight 崩溃均解决；iPhone／Watch 锁屏推送与真实通话仍需回归。
- UI 184 已在 iPhone Air 覆盖安装并启动。模拟器 UI 测试受启动环境阻塞，未完成截图用例，不能宣称全尺寸视觉验收通过。
- 实验性 ANCS 通知转发已撤回，不包含在本次发布。纯本地跨端零 Relay 流量、Watch 全链路仍需专项验收。
