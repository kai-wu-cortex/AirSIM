# AirSIM Apps v0.9.8.16 — 云端音频启动与弱网通话优化

日期：2026-10-27（Asia/Shanghai）。Android Standalone／AVF Bridge `0.9.8.16 (121)`，iOS／Watch／Live Activity `0.9.8 (145)`，从 `VoBLE` 分支发布。

## 更新内容

- **云端音频启动**：云端来电接听后，只要媒体已连接且 CallKit 音频会话已激活，立即启动音频；不再等待可能延迟/丢失的 Agent `active` 控制帧。修复接听后长期无声、看起来像云端卡死的问题。
- **弱网 PCM**：对最多 3 个连续丢失的 20ms 帧做衰减隐藏，避免直接跳帧造成爆音/卡顿；自适应 jitter 上限从 200ms 提高到 240ms，稳定后仍回落低延迟；长断线快速重同步，不播放过期语音。
- **云端自检**：健康检查、设备注册、Agent 状态查询复用一个 HTTPS 会话，减少未开 VPN 时重复冷 DNS/TLS 的等待。
- **历史设备清理**：Relay Dashboard 设备详情新增“删除设备记录”，可删除云端注册、心跳和历史状态；App 本机“已配对设备”删除仍只清本机记录。
- **CallKit/挂断**：来电事件优先 Relay，已结束来电不再迟到拉起；云端 `end`/`reject` 回执超时按本地结束；iPhone 被划掉后 Android 12 秒宽限自动挂断。
- **诊断**：MetricKit 崩溃诊断、最新 Android 日志尾部、音频阶段、PCM client closed、Telecom 状态进入 Notion。
- **反馈键盘**：用户描述/备注支持键盘“完成”和交互式收起。

## 下载与安装

- `AirSIM-Android-Standalone-0.9.8.16-build121.apk`：推荐，单 APK 内置 Agent。
- `AirSIM-Android-AVF-0.9.8.16-build121.apk`：旧 AVF 部署的 Android Bridge。
- `AirSIM-iOS-0.9.8-build145-unsigned.ipa`：包含 Watch 与 Live Activity，需完整重签。
- `AirSIM-iOS-0.9.8-build145-sideload-unsigned.ipa`：不含 Watch、保留 Live Activity，仍须重签。
- `SHA256SUMS.txt`、`LICENSE`、`NOTICE`、`THIRD_PARTY_NOTICES.md`。

正式 APK 使用 AirSIM Release 证书，可覆盖同包名、同签名安装；不要先卸载或清除配对数据。公开 IPA 不含 Apple 签名或描述文件，不能直接安装。
