# AirSIM Apps v0.9.8.17 — VoWLAN 云端通知、通讯录与虚拟来电修复

日期：2026-10-28（Asia/Shanghai）。Android Standalone／AVF Bridge `0.9.8.17 (122)`，iOS／Watch／Live Activity `0.9.8 (146)`，从 `VoBLE` 分支发布。

## 更新内容

- **VoWLAN 保留云端通知**：云端 APNs／PushKit 注册不再由媒体模式决定。VoWLAN 下可单独打开“云端通知（APNs）”，关闭本地模式也不会自动切到“自动”模式；呼叫媒体仍只走 VoWLAN，不会静默回退云端媒体。
- **配对通知配置**：配对时的“仅本次配对不写入云端”只控制 Relay／APNs 写入，不改变通话媒体模式；写入云端后即使当前是 VoWLAN，也会保留来电通知。
- **云端拨号稳定性**：Relay 状态过期时仍保留可拨号的 Agent 目标；自检期间状态查询失败不再阻塞正常拨号；修复云端界面渲染阶段写 UserDefaults 导致的主线程卡死风险。
- **通讯录**：识别 iOS 18 受限通讯录访问，只显示用户已授权联系人并提示进入系统设置选择更多；监听联系人数据库变更，进入通讯录／选择联系人时强制刷新，新增联系人不再被旧缓存挡住。
- **虚拟来电标题**：运行台虚拟来电改用 CallKit generic handle 与 localizedCallerName，非数字标题（如“虚拟来电测试”）可以正常显示。
- **仅手动反馈**：iOS／Android 移除通话、短信自动上传反馈；只保留用户主动“立即上传反馈”。首次更新说明同步修改。
- **Relay 降噪**：Agent 心跳改为 120 秒、在线窗口 150 秒；心跳保留在 Durable Object 热路径，KV 只作只读回退，避免免费 KV 每日写入配额被心跳耗尽；心跳失败 30 秒退避；Dashboard 心跳读取有上限并支持批量清理历史设备。每日定时清理 30 天未注册且当前离线的设备。

- `AirSIM-Android-Standalone-0.9.8.17-build122.apk`：推荐，单 APK 内置 Agent。
- `AirSIM-Android-AVF-0.9.8.17-build122.apk`：旧 AVF 部署的 Android Bridge。
- `AirSIM-iOS-0.9.8-build146-unsigned.ipa`：包含 Watch 与 Live Activity，需完整重签。

- `SHA256SUMS.txt`、`LICENSE`、`NOTICE`、`THIRD_PARTY_NOTICES.md`。

正式 APK 使用 AirSIM Release 证书，可覆盖同包名、同签名安装；不要先卸载或清除配对数据。公开 IPA 不含 Apple 签名或描述文件，不能直接安装或上传 TestFlight。
