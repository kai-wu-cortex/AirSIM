# AirSIM Apps v0.9.8.25 — 蓝牙通话恢复与短信回执

2026-11-14（Asia/Shanghai），基于 `develop`。Android Standalone／AVF Bridge **0.9.8.25（140）**；iPhone／Watch／Widget／短信通知扩展 **0.9.8（176）**。

## 更新内容

- VoBLE 来电由 PushKit 唤醒后，等待对应已配对设备恢复认证，再沿蓝牙接听；固定蓝牙模式不误走云端。恢复有时间上限，严格匹配设备、通话与连接代次，不接管其他通话。
- 优化蓝牙运营商接通前音频的通知合包、队列与协商保活。接通前只接收真实下行，不开启麦克风、不提前计时；不保证运营商每次拒接都有公告。
- 蓝牙地址变化时通过认证身份恢复已有配对；补齐 VoBLE 设备电量、App／小组件展示及 Android 10–12 短信能力检测。
- 修复部分安卓 PhoneAccount 与短信订阅映射；保留精确 SIM 选择，不猜测卡槽或静默切换默认卡。
- Shizuku 短信发送接入系统逐段发送回执。调用异常但系统确认已发送时正确返回成功，并由 iPhone 保存发信记录；结果不确定时不回退重发，避免重复短信。仅系统确认发送不等于对方收达。
- 云端心跳与状态提供按设备隔离的 SIM 列表，拨号和短信传递所选卡；同一个操作不能用重试换卡。需配套新版 Relay 和具备该能力的设备端。
- 整合 Watch 来电状态与终态身份同步、兼容端的直接接听和短信会话／回复，保留媒体授权和旧端回退边界。
- 开屏新增“蓝牙连接与音频”和“短信发送与记录”两组本地 SVG 动画；Android 更新介绍同步，保留减少动态效果支持。

## 升级与限制

- Android 正式 APK 沿用原发行证书；当前 Debug 包不能直接覆盖为正式包，请勿盲目卸载丢失配对数据。
- GitHub full／sideload IPA 为未签名包，需自行配置 Apple Team、Bundle ID、App Group、共享钥匙串并签署全部扩展；full 含 Watch，sideload 不含 Watch。这些包不能直接安装或上传 TestFlight。
- iOS／Android 建议配套升级。独立 AVF Linux Agent 与 U30Air 固件不在本次发布内；不能把 Standalone 的新能力视为这些设备端已经支持。
- 既有缺失的 iPhone 发信历史不会自动补回。Root-only 短信回执、多段短信与更多厂商机型仍待实机验收；厂商发送后的空指针未宣称消失，新版通过系统回执正确收敛结果。
- 运营商语音依赖实际音频下行与设备能力。纯本地跨端零 Relay 流量、Watch 全链路及云端双卡实际出号仍需专项验收。
- 本轮仅发布应用和源码，不另行部署 Worker／ECS。自托管用户需同步包含 SIM 列表与选卡转发的新 Relay 源码。

## 验证与发布状态

- Redmi 9 + iPhone 的蓝牙早期语音流畅性及 140 版短信发送／iPhone 发信记录由用户实测确认。单段短信日志显示同一尝试获得系统成功回执，未触发跨路径重发。
- Android 全套回归通过；权限短信 23 项、API 29–35 能力与回执分类测试通过。Worker 82 项测试通过。
- iOS 蓝牙冷启动恢复、地址认证恢复、早期媒体与正式通话音频一致性、云端 SIM 模型、更新策略、Watch 镜像／传输／可靠性和短信身份定向回归通过。测试使用模拟边界，不等同于真实无线链路验收。
- Android 两种正式 APK 的原发行证书、build 140 和不可调试标志已核验；两张新 SVG 的 XML 和静态预览检查通过。最终归档、发布附件及 TestFlight 状态随后记录。
- 既有云端 SIM XCTest 模拟器宿主未能启动用例；已有构建通过与独立协议 smoke，不宣称该组 XCTest 已执行通过。
