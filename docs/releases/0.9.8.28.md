# AirSIM v0.9.8.28

发布日期：2026-11-27。源码分支：develop。

- iPhone／Watch／小组件／通知扩展：0.9.8（200）。
- Android 本轮没有代码变化，继续使用 [v0.9.8.27（142）正式安装包](https://github.com/kai-wu-cortex/AirSIM/releases/tag/v0.9.8.27)。

## 本次更新

- 短信列表同时显示日期和时间。点通知进入会话后记录已读，兼容冷启动、加密云端短信和后续完整消息同步；按来源设备区分消息，避免误标其他设备的短信。
- 调整短信会话头像、号码、输入栏和渐进式模糊。使用系统页面过渡与交互式返回，改善首次进入、返回手势开始时的输入栏跳动，以及底部标签栏迟到的问题。
- 短信发送结果待确认、设备保护期和发送失败使用中文提示，保留编辑内容。沿用设备的防重复发送保护，不自动重发，也不把“待确认”当作成功。
- 灵动岛增加独立的“显示手机号”和“显示信号”开关。紧凑双卡采用上方信号柱、下方圆点，不再显示卡号数字；未知或过期信号不占用信号位置，已有号码按独立设置保留。
- 改善设备详情空白与灵动岛展开内容截断。更新多设备 SIM 状态，区分信号过期与设备离线；回到前台时重新核对灵动岛状态。
- 改善自动模式锁屏云端接听：没有已验证本地路线、且存在有效云端媒体授权时及时使用云端；返回 App 接管同一通电话，避免重复待接听页面，并处理 CallKit 音频激活与媒体就绪的先后顺序。
- 恢复“设置 → 连接与设备 → 云端 Relay”的服务器地址与音频缓冲配置入口。
- 模块 Agent 与 Relay 增加实际信号采样时间传递；iOS 按设备读取有效的云端模块信号。模块控制链路区分 Relay 状态通知与通话命令，保留原有鉴权与通话身份检查。
- 更新开屏新功能介绍与短信阅读、双卡信号动画 SVG。修复新改动中的 Date 比较运行时兼容风险，并检查最终发布二进制。

## 安装与配套更新

GitHub 提供两种 unsigned IPA：完整包包含 Watch，sideload 包移除 Watch。两者均需自行重新签名；原始签名归档和 dSYM 不公开。

TestFlight 使用 App Store Connect 上传；上传完成后仍需 Apple 处理及测试分发，GitHub 发布不代表 TestFlight 已可下载。

**MU300／U30 Air 云端信号需要 Relay 和模块 Agent 同时支持采样时间。** 本发布包含本仓库对应源码，但不会自动升级已部署服务或独立模块固件。旧 Agent 未上报有效采样时，iOS 继续隐藏未知信号，不借用其他设备信号。本轮没有重新部署 Cloudflare Worker 或阿里云 ECS。

## 验证与边界

- iOS 111 项定向回归通过，覆盖云端冷启动接听、设备身份与路线隔离、SIM 刷新、短信通知已读、加密短信与界面状态。
- 短信返回／键盘／边缘模糊 UI 回归在本轮界面验证中通过；本次发布没有发起真实通话或发送短信。
- SIM 显示、短信中文反馈与保护期、62 项短信身份检查、26 项 iPhone／Watch PushKit 检查、更新策略和 100 台设备目录检查通过。
- Go Agent 完整测试、Relay 87 项测试、真实 workerd 路由集成及自托管 5 项测试通过。
- Release 归档、签名、主 App／Watch／扩展版本及 Date 运行时导入检查通过。

小组件刷新与灵动岛存活仍受系统调度限制。不同模块固件、全部网络和耳机组合未完成端到端覆盖；本次更新不包含已废弃的 ANCS 通知转发。
