# AirSIM Apps v0.9.8.14 — CallKit 接听、VoBLE 短信与音频诊断

日期：2026-10-27（Asia/Shanghai）。Android Standalone／AVF Bridge `0.9.8.14 (119)`，iOS／Watch／Live Activity `0.9.8 (143)`，从 `VoBLE` 分支发布。

## 更新内容

- **CallKit 接听修复**：CallKit 接听改为幂等；云端 early answer 成功后不再重复走本地 VoWLAN answer。修复 `active call id mismatch`：发送 Android Telecom 的 `android_id`，不再发送 iOS 展示用 `android-<timestamp>`。
- **冷启动接听**：通知/CallKit 拉起 App 时最多等待约 2.4 秒恢复 VoWLAN 路由，不再立即挂断；生命周期进入 active 时补启动通话音频。
- **本地配对**：自动/VoWLAN/VoBLE 默认“仅本次配对不写入云端”，不再因 Android push/relay 关闭而阻断 Bonjour 配对；只有显式云端模式要求 Relay。
- **VoBLE 短信下行**：Android 通过已认证 BLE control channel 发送 `sms_event`，iPhone 入库、通知、验证码复制和自动反馈。
- **Relay 地址**：拒绝 `https:`/`http:` 等残缺值，维护者固定回退 `https://airsim-push.remotepilot.site`；发布归档已验证 Info.plist 写入完整 HTTPS 地址。
- **灵动岛号码**：显示完整同步号码，不再使用 `XXXX` 掩码；修复英国、中国等国际号码显示错误。
- **音频诊断反馈**：新增 Notion 字段：音频启动阶段、启动耗时、缺失阶段、PCM 客户端关闭、Telecom 状态、音频诊断。
- **自动反馈**：默认关闭；手动“立即上传反馈”仍可用。
- **VoWLAN 网络自愈**：DHCP 换址丢弃旧 LAN endpoint，保留 100.64 overlay；健康检查首次 401 重新签名重试。

## 下载与安装

- `AirSIM-Android-Standalone-0.9.8.14-build119.apk`：推荐，单 APK 内置 Agent。
- `AirSIM-Android-AVF-0.9.8.14-build119.apk`：旧 AVF 部署的 Android Bridge。
- `AirSIM-iOS-0.9.8-build143-unsigned.ipa`：包含 Watch 与 Live Activity，需完整重签。
- `AirSIM-iOS-0.9.8-build143-sideload-unsigned.ipa`：不含 Watch、保留 Live Activity，仍须重签。
- `SHA256SUMS.txt`、`LICENSE`、`NOTICE`、`THIRD_PARTY_NOTICES.md`。

正式 APK 使用 AirSIM Release 证书，可覆盖同包名、同签名安装；不要先卸载或清除配对数据。公开 IPA 不含 Apple 签名或描述文件，不能直接安装。
