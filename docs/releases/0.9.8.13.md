# AirSIM Apps v0.9.8.13 — 后台保活开关、Notion 自动反馈与 VoWLAN 网络自愈

日期：2026-10-27（Asia/Shanghai）。Android Standalone／AVF Bridge `0.9.8.13 (118)`，iOS／Watch／Live Activity `0.9.8 (142)`，从 `VoBLE` 分支发布。

## 更新内容

- **后台静音音频保活开关**：新增全局开关，默认关闭。关闭后不再用持续静音播放维持后台，降低耗电；PushKit、CallKit、VoWLAN、VoBLE 与云端 Relay 不被关闭。
- **Notion 自动反馈**：通话结束、短信发送或接收时自动上传脱敏日志、设备信息与 PCM 状态；设置页可填写用户描述和备注，也可手动上传。
- **VoWLAN 网络自愈**：Wi-Fi/DHCP 换址后丢弃旧 LAN endpoint 与手动 LAN route，重新发现并验证；保留 Tailscale/100.64 overlay 路由，避免继续探测失效地址。
- **VoWLAN 401 重试**：幂等 GET 收到 401 时用新的 nonce/timestamp 重签一次，不重放拨号、短信等非幂等 POST。
- **通话兼容**：所有厂商统一最低非零音量，避免 VOICE_DOWNLINK 被静音压成全零；修复 OnePlus 等机型 DTMF 音被立即取消、挂断无响应；KernelSU root bridge 初始化 Looper。
- **短信与设备信息**：短信正文复制、验证码复制/自动复制、SIM 卡槽标注；灵动岛每页最多 3 台设备，国际号码保留国家码。
- **首次启动引导**：版本说明改为全屏图文 SVG motion 引导，左右滑动，右上角“确定”。

## 下载与安装

- `AirSIM-Android-Standalone-0.9.8.13-build118.apk`：推荐，单 APK 内置 Agent。
- `AirSIM-Android-AVF-0.9.8.13-build118.apk`：旧 AVF 部署的 Android Bridge。
- `AirSIM-iOS-0.9.8-build142-unsigned.ipa`：包含 Watch 与 Live Activity，需完整重签。
- `AirSIM-iOS-0.9.8-build142-sideload-unsigned.ipa`：不含 Watch、保留 Live Activity，仍须重签。
- `SHA256SUMS.txt`、`LICENSE`、`NOTICE`、`THIRD_PARTY_NOTICES.md`。

正式 APK 使用 AirSIM Release 证书，可覆盖同包名、同签名安装；不要先卸载或清除配对数据。公开 IPA 不含 Apple 签名或描述文件，不能直接安装。

## 验证与已知限制

- Android JVM 测试通过；Standalone 与 AVF APK 均使用 AirSIM Release 证书签名并验证。
- iOS Release archive 成功；TestFlight 上传成功，回执 `Upload succeeded`、`Uploaded package is processing`。
- 上传成功不代表 Apple 已完成处理、外测审核或测试者可更新，以 App Store Connect 实际状态为准。
- 各 OEM 双向音频、双 SIM/eSIM、真实换卡、锁屏长时后台、DHCP 换址和 APNs 全矩阵仍需真机验证。
- 后台音频保活默认关闭；关闭后 iOS 后台轮询可能被系统挂起，普通 Push 仍可用。
- 通知/反馈上传失败会保留本机日志，但不保证自动补传。

## 发布边界

本轮不合并 `main`、不发布新的 AVF Linux Agent（保持 v0.4.7），不重新部署 Relay 协议。Notion 反馈 Worker 已在 `airsim-push.remotepilot.site` 部署；反馈数据写入用户提供的 Notion 数据库。
