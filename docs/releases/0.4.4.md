# AirSIM AVF Agent 0.4.4-1

本版让 AirSIM 与同一 Android AVF Linux 中现有的 DJOneHub 并存，且修复首次安装和状态识别问题。发布前必须使用既有 Ed25519 发布私钥签名全部 Debian 资产；不能仅以构建成功代替签名或真机验证。

## 变更

- AirSIM Agent 改为监听 `8575`，独立 installerd 改为监听 `8576`；不停止或接管 DJOneHub 的 `7575`。
- Agent `/api/health` 返回 `product=airsim`。Android App、installerd 和首次安装脚本校验产品身份，避免将其他服务误认为 AirSIM。
- Android App 将旧 AirSIM `:7575` 配置迁移到 `:8575`，并使用新的私网端口进行自动发现。
- 首次安装脚本先检查 Debian 依赖状态和 AirSIM 端口冲突；若系统包已损坏或端口被占用，在安装前退出。重复执行时优先恢复已有服务，并保留回滚包。
- 更新 AVF 安装、配对与无损排障文档。

## 共存设备安装前检查

1. 在 AVF Linux 中确认 `sudo apt-get check` 成功；若 `udev` 与 `libudev1` 不一致，先按[安装指南](../AVF_INSTALL_GUIDE.md)模拟并核对修复计划。
2. 确认 `7575` 上的 DJOneHub 正常，`8575`、`8576` 未被其他进程占用。
3. 确认下载的签名包版本是 `0.4.4-1`，且内置的发布公钥与上一版一致。不要在共存环境运行旧版 `0.4.3` 的在线安装脚本。
4. 安装后分别验证 DJOneHub `7575`、AirSIM Agent `8575`（`product=airsim`）和 AirSIM installerd `8576`，再进行配对和真实通话测试。
