# AirSIM Apps v0.9.3

AirSIM Apps v0.9.3 为多 Android Agent 场景补齐可见性与自动云端接管。iOS 拨号页现在显示当前路由到的 Android 手机、号码、Agent 类型，以及 VoWLAN 和云端在线状态；同一 iPhone 配对多个 Standalone / AVF Agent 时，可打开完整列表查看每台设备。

## 主要变化

- iOS 拨号页新增“当前 Android”卡片，显示设备名称、手机号码、Standalone/AVF 类型，以及 VoWLAN、云端两个独立状态。
- iPhone 配对多个 Android Agent 时显示“全部 N”入口，列表逐台展示同样的信息；没有可用当前路由时仍可查看离线设备。
- VoWLAN 优先选择本地可达的 Agent；VoWLAN 不可用时，Relay 选择最近 90 秒内最新心跳的 Agent 作为当前云端路由。
- Relay 按稳定 `android_agent_id` 保存多个心跳，同时保留旧版单 Agent 镜像与 `legacy` 兼容项。
- Android Standalone 使用包名和 `ANDROID_ID` 派生不可逆稳定标识，并上报设备名称、厂商、型号与可选 SIM 号码。
- AVF Agent v0.4.6 从已认证的 Android 配对信息读取相同元数据并加入云端心跳。
- 手机号码不进入 Bonjour 广播；VoWLAN 仅在 HMAC 鉴权后的健康接口返回，云端仅通过设备鉴权状态接口读取。运营商未写入号码或用户拒绝权限时显示“号码未提供”。

## Android 更新

1. 下载 `AirSIM-Android-Standalone-0.9.3.apk`，核对本页 SHA-256 和发布证书 SHA-256。
2. 使用 `adb install -r` 或系统安装器覆盖 Standalone；包名仍为 `com.airsim.phonecontrol.standalone`，不会覆盖旧 AVF 版 App。
3. 授予可选的“读取手机状态/号码”权限，才能在 iPhone 显示 SIM 号码；不授权不影响拨号、VoWLAN 或云端模式。
4. 打开 App 确认 Relay 心跳恢复，再在 iPhone 拨号页核对设备名称、号码和当前路由。

## iOS IPA 重签

公开 IPA 是 unsigned 构建，不包含开发证书、provisioning profile 或设备 UDID，不能直接安装。使用自己的 Apple Developer Team 为主 App、Watch App 与 Live Activity Extension 分别配置 Bundle ID、签名和 provisioning profile，并让自己的 Relay 的 `ALLOWED_BUNDLE_ID`、APNs topic 与主 App 一致。完整步骤见 [iOS README](../../iOS/README.md)。

## 安全边界

本项目仅限许可证允许的非商业用途。APK/IPA 不包含 APNs 私钥、Dashboard token、Cloudflare token、AVF 控制 token、Android 发布私钥或 Apple 签名身份。AirSIM 不能替代系统紧急呼叫能力。
