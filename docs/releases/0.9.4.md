# AirSIM Apps v0.9.4

AirSIM Apps v0.9.4 新增真正独立于云端基础设施的“仅本地模式”。开启后，iPhone 与 Android 的配对只交换 VoWLAN 本地密钥，不要求 Relay 地址、设备云身份或 APNs token；iOS 同时停用 PushKit、CallKit 和云端 ActivityKit token 注册，避免推送认证问题阻断局域网配对。

## 主要变化

- iOS 首次连接页和设置页新增“仅本地模式”开关；开启后强制关闭云端模式，并禁用云端开关、Relay 地址和云端自检。
- 本地配对负载只包含 `local_mode`、`cloud_enabled=false` 和 VoWLAN 密钥，不再依赖 Relay、设备 Secret、PushKit/APNs token、Bundle ID 或 APNs 环境。
- 本地模式运行期间停止 PushKit、APNs、CallKit 和远程 Live Activity token 注册；关闭本地模式后恢复系统注册，云端模式仍由用户手动开启。
- Android Standalone 与旧 AVF Agent 均识别 `local_mode`，禁止本地模式重新开启 Relay，并把本地配对视为完整有效配置。
- iOS 拨号页移除重复标题与独立 VoWLAN 横幅，整体内容居中压缩到单页，不需要滚动。
- 锁屏实时活动与灵动岛加入当前 Android 设备名称、号码、Standalone/AVF 类型、配对数量以及 VoWLAN/云端状态。

## Android 更新

1. 下载 `AirSIM-Android-Standalone-0.9.4.apk`，核对本页 SHA-256 和发布证书 SHA-256。
2. 使用 `adb install -r` 或系统安装器覆盖 Standalone；包名仍为 `com.airsim.phonecontrol.standalone`，不会覆盖旧 AVF 版 App。
3. 在 iPhone 打开“仅本地模式”后重新配对，Android 会保存 VoWLAN 密钥并停止 Relay 心跳与云端命令轮询。
4. 如需恢复云端功能，先关闭 iPhone 的“仅本地模式”，再手动开启云端模式并重新配对，使 Android 获得完整云端身份与 Push 参数。

## iOS IPA 重签

公开 IPA 是 unsigned 构建，不包含开发证书、provisioning profile 或设备 UDID，不能直接安装。使用自己的 Apple Developer Team 为主 App、Watch App 与 Live Activity Extension 分别配置 Bundle ID、签名和 provisioning profile；需要云端模式时，还必须让自己的 Relay `ALLOWED_BUNDLE_ID`、APNs topic 与主 App 一致。完整步骤见 [iOS README](../../iOS/README.md)。

## 安全边界

本地模式不会绕过 VoWLAN 的六位配对码、加密交换、HMAC、时间戳或 nonce 校验。公开 APK/IPA 不包含 APNs 私钥、Dashboard token、Cloudflare token、AVF 控制 token、Android 发布私钥或 Apple 签名身份。AirSIM 不能替代系统紧急呼叫能力。
