# AirSIM Apps v0.9.8.19 — 本地出口控制、隧道恢复与短信重试

日期：2026-10-30（Asia/Shanghai）。基于 VoBLE 合并提交 `c1946ec`。
Android Standalone／AVF Bridge `0.9.8.19 (124)`；GitHub iOS／Watch／Live Activity unsigned 包 `0.9.8 (148)`；TestFlight 另用构建 `149`。

## 更新内容

- 合入纯本地模式策略、持久化及 Relay 出口代际控制；旧排队请求不能在关闭再开启云端后继续发送。设置顶部提供滑动入口。
- 云端自检与通话连接模式解耦：纯本地开启时禁止；关闭时支持手动检查 Relay、注册与 Agent 状态。
- Android 增加手动心跳、容量错误退避，反馈仅手动上传；改善反馈粘贴和键盘遮挡。
- VoWLAN 保留已配对 VPN 地址候选，网络切换后重新鉴权；合并并发探测，避免重复验证相互取消。
- 短信上传独立于主 Agent 循环，按服务端错误退避；取消旧配置请求，区分永久拒绝与暂时失败。Worker 短信 APNs 内容限制按字节处理。
- 保留联系人／最近页面、短信导航及通话生命周期修复。未合并 PR11。

## 发布文件

- 正式 Android APK 必须使用原 AirSIM Release 证书，不以 Debug 签名替代。
- GitHub full／sideload IPA 不包含 Apple 签名，需要用户自行重签；不能直接上传 TestFlight。
- TestFlight 使用维护者 Bundle ID `com.eric3u.airsim` 单独归档上传；上传、Apple 处理和外测审核是不同状态。
- 不发布新的 Linux Agent，不自动部署 Worker。自部署用户需单独部署仓库中的 Worker 更新。

## 验证和限制

- 合并代码通过 Android 完整测试、纯本地出口测试、Worker 66 项测试。
- `c1946ec` 曾以旧版本号 Android `123`／iOS `147` 覆盖安装到三星与 iPhone Air并启动；这不是新发布编号 `124`／`148` 的真机验收。
- **纯本地模式仍是实验功能**：当前 iOS 开关的本机出口控制不代表 Android／AVF 已完成认证协商；跨端事务和零 Relay 流量尚未完成端到端验收。不要据此假定两端所有云请求均已关闭。
- VoWLAN／VoBLE、Tailscale、锁屏来电、短信、DHCP 换址及切换模式仍需联合真机复测。
- Relay 配额耗尽不会因升级 App 自动恢复；新版错误提示与退避不能替代服务端容量。
