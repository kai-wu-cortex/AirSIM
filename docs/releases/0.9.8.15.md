# AirSIM Apps v0.9.8.15 — CallKit 接听、挂断与远程失联保护

日期：2026-10-27（Asia/Shanghai）。Android Standalone／AVF Bridge `0.9.8.15 (120)`，iOS／Watch／Live Activity `0.9.8 (144)`，从 `VoBLE` 分支发布。

## 更新内容

- **CallKit 接听**：接听幂等；云端 early answer 成功后不再重复走本地 VoWLAN answer；使用 Android Telecom `android_id`，修复 `active call id mismatch`。
- **来电延迟**：Android 来电事件改走独立优先 Relay 队列，不再排在心跳/命令轮询后面；Relay 超时快速重试；已结束的迟到来电不再拉起 CallKit。
- **挂断回执**：云端 `end`/`reject` 的 final receipt 超时缩短到 8 秒；超时按本地已结束处理，不再弹“等待 Agent 确认通话控制超时”。
- **iPhone 被划掉**：Android 检测云端/VoWLAN/VoBLE owner 丢失后等待 12 秒；重连则取消，仍失联则自动挂断对应 Telecom call。
- **冷启动音频**：CallKit 拉起时等待 VoWLAN 路由；生命周期进入 active 时补启动音频；音频注册遇到瞬态路径错误重试 4 次。
- **配对**：自动/VoWLAN/VoBLE 默认仅本地配对，不再因 Android push/relay 关闭而阻断 Bonjour 配对。
- **VoBLE 短信下行**：`sms_event` 经认证 BLE control channel 到 iPhone。
- **反馈诊断**：自动反馈默认关闭；Notion 新增音频启动阶段、缺失阶段、耗时、PCM client closed、Telecom 状态、崩溃诊断；Android 日志改取最新尾部。
- **反馈键盘**：用户描述/备注支持键盘“完成”和交互式收起。
- **Relay 地址**：发布归档确认 `https://airsim-push.remotepilot.site`，拒绝 `http:`/`https:` 残缺值。
- **灵动岛**：显示完整同步号码，不再使用 `XXXX` 掩码。
