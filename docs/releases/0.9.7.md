## 主要变化

- VoBLE 是设置中的独立蓝牙模式，不依赖 Wi-Fi、Relay 或 PushKit；认证 BLE GATT 传送控制和 AES-256-GCM 加密的 G.711 μ-law 8 kHz 单声道通话音频，不提供 Bluetooth PAN 网络共享。
- 自动模式按实际拨号路由选择 VoWLAN → VoBLE → 云端；蓝牙可用性不再依赖 VoWLAN 配对或 HTTP 200。拨号页、Agent 列表和实时活动显示蓝牙状态。
- 修复临时/权威通话 ID、generation、迟到状态与重复挂断竞态；已认证的同一终态挂断可幂等完成，不会误操作下一通电话。灵动岛蓝牙操作由主 App 的认证会话执行。
- 调整蓝牙音频的有界缓冲、播放补帧和蜂窝上行路由；取消配对后清理双方凭据并恢复扫描，连接超时等待旧 GATT 断开，不创建重叠连接。
- Android 增加 VoBLE 认证配置页、默认通话 SIM/eSIM 选择及启动 Shizuku 检查。缺少 Shizuku 时提供官方下载地址；未运行或未授权时提供对应入口。
- Android 闪退报告仅在用户选择发送时进入系统分享面板，限制大小并脱敏，不自动上传。
- iPhone 可手动绑定 Agent、删除已配对设备和最近通话。设备历史不缓存号码；新 APK 的 BLE、VoWLAN 与 Standalone 心跳读取当前通话卡信息，号码不可读时不借用旧号。
- 补齐诊断 Debug 包内嵌动态库的独立签名核验说明，避免漏签导致启动前 DYLD 闪退；正式发布使用 Release 构建，不复用诊断包。

## 验证与已知边界

发布前重新执行 iOS 92 项 XCTest、Android 共享 Bridge/Standalone 测试、47 项 PCM 桥检查、Relay 46 项测试及语法检查、Go Agent/installer 测试。正式工件另行核对版本、Android 证书、不可调试属性和 Apple 嵌套目标签名。

此前 iPhone Air 与三星 Flip7 已进行真实 BLE 通话，用户确认声音已到 iPhone、后续通话正常；日志有双向媒体与结束清理证据。设备列表真机可正常打开。完整逐轮证据见 [真机测试矩阵](../voble-real-device-test-matrix.md)，不能把历史失败场景或单元测试当作本版全硬件验收。

- 纯 BLE 挂断竞态已有双端回归测试，最终真机复测、真实换卡/删除后重配、双卡运营商路由、多厂商音频与 30 分钟稳定性仍需验收。
- Apple Watch 不直接连接 Android BLE；镜像来电与音频由 iPhone/watchOS 系统管理，尚未完成 Watch 真机联合验收。
- iOS 被用户强制退出后不保证 BLE 后台唤醒。通话开始后锁定传输，不在三种路径间无提示漂移。
- 旧 Linux AVF Agent 的云端号码心跳仍读取注册 metadata，尚未迁移到当前 SIM 查询。
- 诊断真机曾出现 ActivityKit `SessionCore.PermissionsError Code=3`，未将启动闪退修复宣称为所有实时活动权限问题已解决。
