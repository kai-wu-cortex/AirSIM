# AirSIM Apps v0.9.8.22 — 灵动岛、设置与安卓兼容性改进

2026-11-04（Asia/Shanghai），基于 develop。Android Standalone／AVF Bridge **0.9.8.22（127）**；iPhone／Watch／Widget **0.9.8（169）**。

## 更新内容

- 灵动岛统一 Wi-Fi、蓝牙、双通道组合、云端和离线图标，覆盖紧凑态、最小态、展开态与设备列表。双通道组合表示两条本地链路均在线；活动内容过期不会直接判定设备离线。
- 开屏更新介绍优先展示新版灵动岛、设置分类和短信搜索，保留 U30Air、小组件、试验性 TLS 公网及未读／未接提醒说明。
- 设置页面按用途分类、减少重复入口并优化滚动性能；底部标签保持展开，调整图标尺寸及顶部滚动过渡。
- 短信支持搜索联系人、号码和内容；大尺寸小组件最多展示最近五条通话与短信，保留未读／未接标识、电量和设备／模式切换。
- 修复 iOS 27.2 部分运行时上的 Date 比较符号兼容问题，避免相关调用触发启动或连接期间崩溃。
- 通用 Android 应用新增 Agent 音频能力检测和具体适配提示，改进 Root／Shizuku 权限通道生命周期、PCM 音频路由及 SIM 号码显示。包含 Redmi 9 机型适配，但不拆分厂商 APK。
- 集成 PR #29 的通话身份、结束状态与短信 SIM 线路处理，保留拨号操作去重和接通前只收音频约束。
- 仓库加入复用 Worker 逻辑的自托管 Relay 部署方案；本次发布不会自动修改用户的服务器。

## 更新与兼容性

- Android 正式包沿用原发布证书。Debug／第三方重签名包可能无法直接覆盖；本发布不要求卸载现有应用或清除配对。
- GitHub 的 full／sideload IPA **未签名**，必须用自己的 Apple 开发者身份签名；full 包含 Watch，sideload 不含 Watch。主 App 和小组件的 App Group 必须匹配。
- PR #29 需要兼容 Agent 与 Worker。维护者的 Cloudflare Worker 已于本次发布前部署兼容版本；自建服务需按 [协议兼容说明](../reviews/pr29-api-compatibility.md) 更新。U30Air 由其设备端项目同步，不能把更新 iPhone 当作已升级设备。
- 不发布独立 AVF Linux Agent 或 U30Air R18 固件。U30Air R18 仍暂停发布，设备端联合验收独立进行。
- 运营商早期媒体需设备与运营商提供下行音频，接通前不提前计时、不启用麦克风上行；不保证所有拒接或挂断都有公告。部分安卓机型已由用户完成双向声音验证，不代表全部品牌／系统兼容。
- TLS 公网功能仍为试验性，需自建可入站网关、有效证书和独立音频转发；小组件刷新由系统调度；纯本地跨端零 Relay 流量仍需端到端验收。

## 验证与发布状态

iOS 全部 489 项单元／集成测试通过；Android Standalone 测试通过；两种正式 APK 的包名、版本、非 Debug 标志和原发布证书已核验。iOS production 分发包已核验主 App／Watch 的 APNs、主 App／Widget 的 App Group、不可调试及深度签名。unsigned full／sideload 包均已验证版本 169 和无签名内容。Date 运行时导入检查通过。TestFlight 169 已于 2026-11-04 21:52（北京时间）上传成功；Apple 返回 `Upload succeeded` 与 `Uploaded package is processing`，尚未确认处理完成及外测可用。新版开屏首页已在 Duo 模拟器展开屏检查，无文字遮挡。模拟测试不能替代锁屏来电、双向通话、VPN／Wi-Fi 切换、多卡短信及运营商早期媒体的真实设备验证。
