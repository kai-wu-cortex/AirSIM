# AirSIM Apps v0.9.8.18 — VoWLAN 云端通知、通讯录、短信与 Watch 响铃

日期：2026-10-29（Asia/Shanghai）。Android Standalone／AVF Bridge `0.9.8.18 (123)`，iOS／Watch／Live Activity `0.9.8 (147)`，从 `VoBLE` 分支发布。

## 更新内容

- **VoWLAN 保留云端通知**：云端 APNs／PushKit 注册与媒体模式解耦。VoWLAN 可单独打开“云端通知（APNs）”，关闭本地模式不再自动切到“自动”模式；接听仍优先 VoWLAN，不静默回退云端媒体。
- **通讯录**：识别 iOS 18 受限通讯录，提示选择更多联系人；监听联系人数据库变更，进入通讯录／选择联系人时强制刷新，新增联系人不再被旧缓存挡住。
- **短信会话**：短信详情覆盖 Tab 栏，新增日期分组、原生文本选择、长按复制、多选删除与系统分享；删除只影响此 iPhone 的 AirSIM 记录。
- **Apple Watch 撤铃**：iPhone CallKit 接通或结束时同步 WatchConnectivity 状态；Watch 结束独立 CallKit 响铃，迟到 APNs 不会重新拉起；补充 call ID／UUID／alias 匹配和 tombstone。
- **CallKit 接听**：系统接听前尽力配置音频，但预配置失败不直接挂断；接听后等待 VoWLAN 路由恢复，冷启动只使用当前绑定设备与专属凭据。
- **Relay 401 恢复**：Standalone 只有 HTTP 401 触发重新注册，退避 1／2／4…60 分钟；心跳成功且其他通道不再 401 时复位。Dashboard 删除在线设备属于清理，不阻止自动恢复。
- **开屏新功能**：iOS 首次更新说明同步改为云端通知、通讯录、短信会话和 Watch 撤铃。
