## 主要变化

- 三星 VoWLAN 控制与 PCM 监听首选端口改为 `7592/7593`，避开 DJOneHub 的 `7590/7591`。首选端口被占用时仅在已选热点地址上绑定系统分配端口，并通过 Bonjour 公布实际控制/PCM 端口，避免 `BindException` 使服务卡在准备中。
- Android 状态页明确当前 VoWLAN / 云端 / 离线模式，诊断链路更易区分。
- iOS 设置页显示传输模式与状态，提供云端模式四阶段自检：本机 Push 凭据、Relay 身份、设备注册、Agent 心跳。自检不会拨号或发送短信。
- 云端通话 PCM 增加有界接收缓冲、播放完成后补帧，以及 20 毫秒节奏的单路发送队列，减少网络突发与连续发送导致的卡顿风险。与既有 Relay PCM 协议兼容。

## Android 更新

1. 下载 `AirSIM-Android-0.9.1.apk`，核对 SHA-256 与上述发布证书指纹。
2. 已安装正式签名 v0.9.0 的设备可直接覆盖更新，保留本地配对资料。若设备仍是旧 debug 签名包，则无法覆盖；先记录 AVF 地址和配对资料，再卸载旧包并安装新版。
3. 启动三星端 AirSIM，确认它仍是默认电话 App 且 Shizuku 已授权。确认 VoWLAN 状态为就绪，诊断中可看到实际控制/PCM 端口；若 DJOneHub 同机运行，不应再出现端口 `BindException`。
4. 在 iPhone 与三星同热点时复测拨号、接听、挂断及双向语音。再切换云端模式，用设置页自检确认 Relay/注册/Agent 心跳，再在真实通话中检查音频。

## iOS IPA 重签

公开 IPA 是 unsigned 构建，不包含开发证书、provisioning profile 或设备 UDID，不能直接安装。需要用自己的 Apple Developer Team 为主 App、Watch App 与 Live Activity Extension 分别配置 Bundle ID、签名和 provisioning profile，并让自己的 Relay 的 `ALLOWED_BUNDLE_ID`、APNs topic 与主 App 一致。完整步骤见 [iOS README](../../iOS/README.md)。
