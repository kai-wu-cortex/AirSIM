# AirSIM Apps v0.9.8.24 — 云端缓冲、短信加密与来电通知

2026-11-08（Asia/Shanghai），基于 develop。Android Standalone／AVF Bridge **0.9.8.24（135）**；iPhone／Watch／Widget／短信通知扩展 **0.9.8（175）**。

## 更新内容

- 云端音频增加自动（默认）、稳定优先与手动缓冲。自动保留现有策略；稳定优先目标 240–720 ms；手动提供 240/480/720/960 ms。更大缓冲可能减少短暂卡顿，同时增加对话等待，不是网络延迟修复。入口：设置 → 连接与设备 → 通话连接方式 → 云端音频。
- 通话开始时固定缓冲选择，重连沿用；挂断清空旧声音。不延迟采集发送，不改变 VoWLAN／VoBLE 音频。兼容新版 Standalone 同步应用；旧 Agent 仅 iPhone 接收侧生效。
- 整合兼容端云端短信端到端加密及 iOS 通知扩展解密，接收 SIM 信息随密文保护；需双方和 Relay 协商，已有配对请检查加密状态，不能假定升级即已加密。Relay 更换与重新配对保留密钥隔离规则。
- 改进双卡来电、未接历史及通知清理；只有明确未接事实才生成提醒，按设备、通话与代次去重，避免跨设备误清理。
- 新增运营商接通前语音开关，保留 VoWLAN、VoBLE、云端全部模式。兼容设备提供真实下行后停止本机等待音，不提前计时或开启麦克风。
- Android 对已确认挂断阶段的本机输出隔离最多延续 2 秒；普通媒体断线恢复本机接管。保留采集音量策略，不统一强制零音量或全局麦克风静音。
- 保留 VoBLE 重连、通话终态与音量耦合设备修复；修复未接提醒中可能引入不兼容 Date 比较运行时符号的代码。
- 开屏介绍及 SVG 动画更新为云端缓冲、运营商语音、短信加密和 SIM／未接提醒，同时保留 U30Air、小组件与试验性 TLS 功能说明。

## 升级与兼容

- Android 正式 APK 沿用原发布证书。当前装有 Debug／第三方签名包时无法直接覆盖，请不要为升级盲目卸载并丢失配对数据。
- GitHub full／sideload IPA 未签名，必须自行配置 Apple Team、Bundle ID、共享 App Group 和共享钥匙串，并签署全部扩展；full 含 Watch，sideload 不含 Watch。不能直接安装或上传这些 unsigned IPA。
- TestFlight 构建使用 production APNs；上传成功、Apple 处理、外测审核与测试者可用是不同状态。
- 本次不发布 U30Air 固件或独立 AVF Linux Agent。U30Air 云端缓冲候选代码已在独立线程完成，但尚未安装验收；旧设备端也可能缺少新版 SIM／未接通知字段。更新 AVF Bridge APK不等于升级 Linux Agent。
- 运营商语音依赖真实下行与设备能力，不保证每次拒接都有公告。纯本地跨端零 Relay 流量仍需端到端验收。通知异步投递存在边界，不能承诺所有场景恰好一次。
