# AirSIM v0.9.8.27

发布日期：2026-11-24。源码分支：develop。

- Android Standalone／AVF：0.9.8.27（142），使用原发布证书。
- iPhone／Watch／小组件／通知扩展：0.9.8（188）。

## 本次更新

- 恢复用户熟悉的拨号、最近通话、短信头像和通话 UI，保留既有通话、连接与短信修复。
- 新增端点管理：可单独删除失效地址，保留设备配对、短信与通话记录；同一设备、同一主机及传输类型的新端口通过身份验证后替换旧端口。删除的地址不会被普通后台发现自动加回，显式重新配置可恢复。通话中不允许删除。
- 灵动岛和小组件按 SIM 显示已有号码与对应信号；信号未知或过期不再替换号码，修复安卓双卡采样混用。
- 移除配对设备与小组件目录数量限制，灵动岛保留分页展示；云端设备列表支持完整分页。
- 安卓 Agent 与 iOS 归一化兼容的 IMS SIP／TEL 来电号码，改善来电展示与联系人匹配；非电话号码和无法安全解释的格式保持原值。
- 包含 PR #46 的同网段局域网恢复、候选优先级和通话路线保护修复。
- 修复局域网探测重试中新引入的 Date 比较运行时兼容风险，保留原有重试时间边界。
- 更新开屏新功能介绍，新增端点管理动画 SVG 和号码保留示意。

## 安装说明

Android APK 使用原发布签名，可覆盖对应正式签名版本。Debug 安装包无法直接覆盖。

GitHub 的完整 unsigned IPA 包含 Watch；sideload unsigned IPA 移除 Watch。两种 IPA 均需自行重新签名，不能直接安装。原始签名归档与 dSYM 留存在本机，不作为公开资产。

TestFlight 使用独立的 App Store Connect 上传流程；是否可下载还取决于 Apple 处理和测试分发状态。

## 范围与限制

- 不含实验性 ANCS 通知转发，也不更新 U30Air／MU300 固件或独立 AVF Linux Agent。
- 号码来自设备已提供的信息，无法凭空读取未写入或未上报的号码。多卡信号需要兼容安卓；未知信号不冒充零格或其他卡信号。
- 小组件刷新由系统调度，不能承诺每次滑到桌面立即刷新。
- 端点管理针对直连地址与本地配对记录；不会删除云端注册或改变 Relay 鉴权协议。
- 本次发布检查不包含真实拨号或短信发送，不宣称全机型端到端验证完成。
