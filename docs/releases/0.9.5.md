# AirSIM Apps v0.9.5

本版修复 Android Standalone 收不到运营商短信的问题，并改善短信发送等待、来电拒接、麦克风授权与本地通话音频上行恢复。AVF Agent 仍为独立的 `v0.4.6`，Relay 协议未变。

## 主要变化

- Android 两种运行模式新增运营商 `SMS_RECEIVED` 接收器与 `RECEIVE_SMS` 授权。Standalone 把收到的短信持久化后提供给 iPhone 的 `/api/sms` 和事件流；AVF 模式在 Agent 暂时离线时也会保留待转发短信。
- Standalone 的本地确认与 Relay 投递分别记录，避免 iPhone 确认后、云端尚未收到时丢弃短信。
- 本地短信发送等待窗口按 Android 系统回执及 AVF Agent 的最长执行时间调整，避免 iPhone 在 Android 仍处理时过早报超时。
- iOS 首次进入前台就请求麦克风权限，不再等到重新配对或通话音频启动。
- Android 拒接优先选择响铃中的来电；若通话已接通则执行挂断，并接受系统已移除通话作为结束确认。
- DTMF 弹窗使用 Liquid Glass 按键和按压高亮、缩放与触觉反馈。
- iPhone 本地 PCM 麦克风上行的发送错误不再被静默忽略，会触发有界重连；诊断统计只累计成功发送的帧。

## 安装与验证

Android Standalone 包名仍为 `com.airsim.phonecontrol.standalone`，可用 `adb install -r` 覆盖安装。升级后打开 Android App，并允许新增的“接收短信”权限；没有此权限不会收到运营商短信。

公开 IPA 不含 Apple 签名或 provisioning profile，不能直接安装或提交 TestFlight。为主 App、Watch App、Live Activity Extension 配置自己的 Bundle ID、Team 与 profiles；云端模式还要求 Relay/APNs 凭据匹配。参见 [iOS README](https://github.com/kai-wu-cortex/AirSIM/blob/v0.9.5/iOS/README.md)。

Android Standalone/Core 测试、iOS 模拟器测试、iOS Release `iphoneos` 归档均通过；APK 为 `0.9.5 (78)`，`minSdk 29`、`targetSdk 35`、`debuggable=false`，`apksigner verify` 通过。发布时没有连接可用的 Android/iPhone 真机，因此运营商短信、真实来电拒接与双向音频仍需在实际设备和网络环境复测；本版不宣称已消除所有机型的语音路由限制。
