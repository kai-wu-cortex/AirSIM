# Android Agent 音频自动检测

状态：2026-11-03，VoBLE 工作树中的未发布改动。适用于共用 Android Bridge 界面的 Standalone / AVF Bridge；检测对象是安卓端的特权 PCM 音频桥，不是 Linux Agent 的在线状态。

## 用户入口

首页配对按钮上方新增「Agent 自动检测」。打开首页后每秒读取音频桥状态，也可点击「重新检测」。结果按问题列出待排查或适配的方向，文字可长按复制。原「PCM 音频桥」状态改为「进程运行」，避免把进程存活理解为双向通话可用。

| 检测结果 | 页面反馈与处理 |
| --- | --- |
| 特权查询明确缺少现有桥支持的 Telephony Tx / 三星 VOICE_TX 接口 | “当前设备暂不兼容 AirSIM · 需要适配”，指出通话上行注入后端缺失；配对和短信不因此禁用 |
| 权限未就绪、用户服务不可达、端口查询失败 | 提示授权、服务或查询问题，不能据此判定处理器不兼容 |
| 下行采集 / 上行播放初始化或读写失败 | 分别列出采集源、权限、AudioRecord、AudioTrack、上行路由或采样格式方向 |
| 音频端口格式与桥的 8 kHz 单声道 PCM16 不同 | 提示采样率 / 声道转换待验证；系统可能自动转换，不直接判定不兼容 |
| 通话中上行实际路由落到其他设备 | 提示上行路由异常；三星隐藏路由保留“待验证”，不据此终止通话 |
| 双向 PCM 停止推进或统计过期 | 提示对应上下行及网络 / 音频线程排查方向，不直接归因芯片 |
| 空闲、尚未接通、只有单向早期媒体、静音 | 待验证，不伪造通话、不自动拨号或采音 |
| 观察到上下行数据推进、非零幅度及通话发送路由 | 显示“已观察到双向 PCM 链路”，仍需双方实际听音验收 |

这里只描述当前系统与现有 PCM 桥的兼容情况，不按“联发科 / 高通 / 猎户座”一刀切。Redmi 9 的已知证据和适配建议见 [Redmi 9 MTK PCM 方案](android-redmi9-mtk-pcm-plan.md)。

## 实现与边界

- Helper 启动时只读枚举音频端口及接口，发出 `audio_capabilities` 白名单事件。枚举失败记为 unknown，不当作缺少硬件；不会创建 AudioRecord / AudioTrack 或改路由。
- 现有认证媒体会话正常运行时，继续使用 `client_ready`、`pcm_stats`、启动错误和实际路由事件。路由变化会撤销旧的已验证状态。检测不改变 PCM 协议、授权、会话门控或通话路由策略。
- 统计保留字节数、幅度、错误类别和固定能力标签，不存储音频、电话号码、token 或任意原始错误内容。数据仅用于本地显示；不会主动上传反馈。
- 主页面使用最多 5 秒的最新状态，并绑定特权服务连接代数；断连、连接切换或状态读取失败时不复用上一连接的“正常”结论。
- 判断停滞前，要求 Telecom 已接通，且媒体会话已建立至少 10 秒。统计超过 4 秒未更新提示过期；仍有统计但某方向 8 秒无字节推进时指出该方向异常。静音帧会推进字节，不等同断流。
- 非零峰值只是该会话曾观察到非静音数据，不是语音可懂度、对端实际听到或端到端质量证明。网络丢包、路由抖动、系统静音仍需实机验证。
- 「重新检测」重新读取服务状态，不会重启桥或中断通话。启动时的端口能力枚举若因权限失败，修复授权并重新连接权限服务后再次获取。
- 旧 helper 没有新字段时显示检测信息不完整，不能被视为适配通过。正式发布时须递增 APK versionCode，让现有按安装 build 编号管理的 Shizuku 用户服务更新；当前开发构建未修改发布版本号。

## 验证与实机清单

自动化覆盖能力缺失和查询失败的区分、格式不匹配、权限失败、音频初始化失败、空闲 / 未接通 / 静音、双向数据推进、上下行停滞、统计过期、路由变化及恢复、连接切换、旧会话证据清理和隐私白名单。

执行 `sh android-standalone/test.sh`：包含核心测试、音频桥单元及启动失败测试、Standalone APK 编译、直接 PCM 和云端队列等回归。不发起真实通话、不发送短信、不录音。

2026-11-03 实际结果：上述完整脚本通过，新增检测测试 39 项断言、音频桥单元测试共 71 项断言通过；`git diff --check` 通过。开发测试包生成于 `android-standalone/build/android/AirSIM-Android-Standalone-debug.apk`，不是正式签名发布包。编译保留已有弃用 API 警告。

实机待验收（用户手动测试）：

1. 未授权时只提示权限 / 服务待检查，不报硬件不兼容。
2. 授权后首页显示能力结果，空闲保持双向待验证。
3. Redmi 9 / 三星分别配对后正常拨打、接听，双方轮流说话，核对上下行及路由；格式提示不能代替实际听音。
4. 通话中断开 iPhone 媒体连接，确认提示断流或统计过期；恢复后新会话不继承旧正常或旧异常。
5. 用户静音、等待接通、早期媒体、挂断返回空闲，不误报硬件不兼容。
6. 重启权限服务、从 Root 切换 Shizuku 或更换连接，确认旧检测结果失效。

此功能是诊断与适配提示，不包含新的 MediaTek 音频后端实现。当前未将包含本功能的包安装到 Redmi 9，也未实测双向通话。
