# 手动心跳与反馈输入

Android「设置」的 Agent 刷新结果下新增「立即发送云端心跳」。操作不拨号、不发送短信，不自动开启云端模式。

- Standalone：在后台刷新现有设备注册，再提交心跳；只有 Relay 返回成功才显示接受结果。注册与心跳绑定同一次纯本地门禁代际，快速关闭/开启后旧操作不能续发。
- AVF：调用经过现有控制鉴权的 `POST /api/push/heartbeat`，需要同步升级 Linux Agent。旧 Agent 返回 404 时不能据此认为 Relay 故障；应先升级 Agent。
- 纯本地开启、云端关闭、未配置、Agent 未运行及网络/鉴权错误均不能显示成功。
- 手动成功只是当次心跳得到接受，并不能证明周期性心跳、APNs 或通话媒体链路正常。

Android 反馈的描述、备注提供独立粘贴按钮，按当前选择范围插入文字；仅在点击时读取剪贴板。保留长按编辑。Android 11 及以上按 IME 和系统栏边距调整内容区域，旧版使用窗口 resize。

iPhone 设置分组统一为「安卓连接」，配对行为不变。

## 真机检查

1. 关闭纯本地、确认云端配对已完成。在 Android 点击手动心跳，等待 Relay 接受，再立即运行 iPhone 云端自检。
2. 等待超过 150 秒再自检：确认周期性心跳持续工作；若再次过期，导出两端日志继续调查，不用重复点击掩盖问题。
3. 开启纯本地后点击心跳，应提示禁止发送；切换过程中不能显示旧操作成功。
4. 断网后发送应显示失败；恢复网络后可重试。
5. 反馈描述和备注分别测试中文、多行、选中文字后粘贴；弹出键盘后光标及当前输入框应可见、可滚动。关闭键盘后页面恢复正常高度。

此文档为测试清单，不代表真机验收已经完成。
