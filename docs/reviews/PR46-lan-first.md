# PR #46：同网 VoWLAN 优先

评审日期：2026-11-21。上游提交：`b7c75c5e1d1580afd9c87918db9a652c3baf1f38`；基于 develop `1a5138f` 隔离整合。

## 结论与范围

接受同网地址先探测的需求，补齐候选合并边界后整合。仅修改 iOS VoWLAN 发现/恢复与测试，不涉及 UI、Android、Worker、ECS 或 POST/音频协议，因此无需 U30Air Agent 同步协议变更。

- Bonjour 同网地址优先；尚无 Bonjour 时，可尝试这台已配对设备保存的同网地址。
- 本 PR 的历史地址恢复限定于已有 Tailscale 手动路线的设备，不扩展成任意网段扫描。
- 同网地址失败或处于退避窗口时保留同设备的 VPN 回退；TLS 及已验证/通话锁定路线保持稳定。
- 历史地址仍只是候选；沿用现有签名健康检查、设备身份校验、过期请求保护和通话期间回退限制，不直接宣告在线。

## 评审发现并修正

1. 原 PR 用第一条发现结果覆盖同设备其他候选。失效/异网 Bonjour 会遮住可用的缓存同网地址，随后又先探测 Tailscale。改为优先保留可探测的同网候选；两者都可用时仍优先新 Bonjour。
2. 原有 merge 的 preferred 保护只对手动地址生效。PR 新增的历史 LAN 地址未必存在于手动地址表，已验证或通话锁定后可能被后续 Bonjour 更新替换。增加按设备保留 live 中 preferred 地址的处理；没有任何获准候选的设备不能靠旧 live 数据复活。
