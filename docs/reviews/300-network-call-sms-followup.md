## 行为变化

- 网络：安卓同时监听可用 Wi-Fi／热点地址，保持仍有效的主监听器，避免新增接口反复拆建连接。iPhone 优先使用当前同网段地址，恢复前重新验证设备签名；局域网与 VPN／TLS 分别使用 2.5 秒、8 秒健康探测预算。临时故障采用有限恢复窗口和带随机抖动的重试，鉴权失败立即撤销可用状态。
- 恢复顺序：重新订阅时先获取当前通话快照，再在空闲时补短信和历史归属地。旧订阅和退避可取消；地址回退保留通话保护，诊断展示当前连接、最近验证、恢复耗时及安全错误原因。
- 通话与音频：保留同一通话身份、明确结束证据和来电空快照宽限；补充可追踪的 CallKit 生命周期日志。重整音频桥所有权、启动租约、重启预算和健康证据；输出切换采用有限重试并保留用户选择。应用内通话页采用系统风格布局和玻璃控件，外接耳机时提供带选中标记的多路输出菜单；AirPods 外形按蓝牙名称识别。
- 安卓熄屏：远程静默通话原本熄屏时，在有边界的挂断保护窗口内处理系统唤醒；用户主动亮屏、本地通话和其他通话不适用。不能保证所有厂商系统组件完全不产生瞬时亮屏。
- 归属地：优先使用安卓精确号码匹配的系统通话记录归属地，缺失时回退离线库；支持历史记录批量补全。推送带入 SIM 和归属地元信息，但不宣称本次解决新反馈的 CallKit SIM 显示回归。
- 短信：完善本地连接错误、同步与已读回执，保留加密与去重；手机和手表加入运营商、银行、快递图标，联系人照片优先，仅精确匹配维护的服务号码。图标来源见 `docs/SMSCarrierIcons.md`。
- 手表：当前源码以短信首页、缓存显示、iPhone 协同及可用时的直连刷新为主；相比 PR #36，已经移除 Watch 独立 CallKit／PCM 通话实现和相关旧 smoke 脚本，不是继续交付旧 PR 的手表独立通话预览。
- 推送诊断：记录安卓收到、上传、Relay 收到及 iPhone 收到时间；没有历史时间时明确显示缺失，不将跨设备时钟差当作精确传输耗时。统一应用内诊断和修复入口。
- 资源：更新手机／手表应用图标和离线归属地数据，附带资源来源与许可说明。
