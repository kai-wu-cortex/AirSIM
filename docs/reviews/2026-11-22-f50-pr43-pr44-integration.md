## 已修复

### 云端挂断发送不再无限等待媒体写入

媒体 `ended` 发送等待上限 750 ms。发送线程数量有界，不排队；遇到写阻塞、音频写锁占用、发送失败或执行容量耗尽时，关闭该通话捕获的 socket，继续 HTTP 生命周期路径。终止状态禁止媒体重新连接。

HTTP 上报失败也会释放本通音频，但保留原通话身份供现有有限重试使用。终止事件发生 409 身份冲突时不会采用服务器返回的新通话身份发送挂断，避免旧事件错误结束新通话。普通断网或普通关闭不会制造原生 ended。

回归覆盖：不可被 interrupt 解除的写等待、音频写锁占用、立即发送失败、HTTP 失败后资源释放与原身份重试、迟到终止事件与服务器新身份冲突，以及已有的不同通话身份隔离。

### 配网服务增加通话保护

切换 Wi-Fi、恢复热点、关闭热点、网页重启执行前检查 Telecom 与音频状态。响铃、拨号、通话、非普通音频模式或状态不可读时不切换；连续确认空闲 30 秒后恢复，覆盖通话结束后的语音收尾。采样间隔异常或服务暂停不计入连续空闲时间。重启延迟执行前再次检查。

此保护不改 AirSIM 的通话路由选择；状态无法读取时采取保留当前网络的行为，需通过 USB 检查权限。

### 双卡保持先核验支持状态，再写设置

每轮监督按顺序执行：显式启用标记 → 系统启动完成 → 辅助 APK 签名 → 无副作用的固件 status → 通话空闲 → 再次确认启用 → 系统设置写入 → pulse。

不支持固件、查询异常、签名异常、通话忙碌或启用标记撤回均不会进入写入路径。缺少 `dsds-keep-enabled` 时默认关闭，构建、安装说明中的常规流程与启动脚本不自动创建此标记。保留原先所有者手动启用方式及删除标记回退方式，不强制关闭任何 SIM。
