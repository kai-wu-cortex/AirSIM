# iPhone 204：自动核实安卓挂断结果

此前只查询一次；安卓异步结束尚未落入历史时，会留下未确认提示。现在首次未确认或请求失败后，自动查询原通话状态：前 10 次间隔 2 秒，之后间隔 15 秒（另加每次请求耗时）。仍未确认时展示未返回结束记录／连接异常，不将未知误当作成功。查询成功后显示成功反馈，沿用 5 秒隐藏。

VoWLAN 所属通话重连后优先使用同一 agentID 当前已认证连接；兼容旧路径使用原 API。所有查询继续要求原通话 ID 的明确终态。仅查询，不重复发送挂断，不改变路由或音频。新挂断取消旧复查；旧请求在返回后再次核对作用域，防止覆盖新反馈。收到终态确认会取消复查任务。

复查在 App 获得执行机会时进行，不承诺 iOS 挂起或强制退出期间持续运行。没有原通话 ID 的情况不能安全推断目标，保留异常而不猜测其他通话。
