# iPhone 197 / Android 138 兼容回移

基线：Codex 定制 iPhone 196（7482013，195 的小组件刷新重试增量）、Android 独立测试版 137。
来源：作者发布标签 v0.9.8.24（c38bbf0），其中 E2E 集成 ec94100 / 63c3d4e、安全修正 4a6cc37、通知适配 3973e15。

## 纳入

- 按明确设备、源通话 ID、可用 UUID/代次比对清理通知。缺少 agent 不匹配其他设备；本地未接提醒等候 2 秒并检查已送达 APNs，迟到云端提醒由通知扩展清理本地同通话提醒。
- 只有明确未接事实生成未接提醒；已经接通过的记录保留接通证据。SIM、号码和接通时长保留现有字段。
- 接听命令 ACK 不直接进入 active，等待认证通话事件。重复 PushKit 仍报告现有系统 UUID，不结束现有通话。Android 只让对应原生 call_id 的 ended 结束当前通话。
- Android→iPhone 云端接收短信 AES-GCM 信封与通知扩展解密。发送人、正文、验证码所在正文及接收 SIM 在密文内；AAD 绑定设备、Agent、delivery_id。
- 加密协商要求双方支持、Relay capabilities.e2e_sms=1、共享钥匙串可写及重新配对。旧配对不自动声称加密。损坏钥匙或已协商后的认证失败不退回明文。
- 只在密封配对请求发送主钥匙；注册转发字段白名单不含钥匙。认证网关成功后提交 iPhone 暂存钥匙，写入失败可重试。Relay 更换和忘记设备清理对应钥匙。
- Relay 云端 SMS 选卡与 SIM 通知字段纳入源码以匹配已存在的线上修复；推送去重增加 Agent 和代次，迟到 active 不恢复终态。

## 保留 / 跳过

- 已有双卡字段、通话历史保存及小组件 195/196 功能保留，不整批覆盖作者 UI 或小组件实现。
- 专用 VoWLAN 通话策略保留；Relay 不承载通话媒体，不开启 VoBLE / 云端通话。
- 不采用作者普通媒体断线恢复本机出声、非零输出音量或移除全局麦克风隔离的策略。保留 Android 137 已实测的静音、麦克风隔离与挂断无漏音实现。
- 不合入云端缓冲、开屏动画或其他无关功能。
