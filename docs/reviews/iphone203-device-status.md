# iPhone 203：设备卡片状态

VoWLAN 专用模式下，拨号页及设备选择列表保留 VoWLAN 状态，将 VoBLE／云端音频状态替换为推送检查与短信加密状态。非专用模式保留原有展示。

推送检查只读通知授权、Relay 身份检查及对应 agentID 的 Relay 心跳；检查通过仅代表上述条件通过，不证明 APNs 实际送达。通知关闭、未授权、设备未注册、心跳过期和检查失败分别展示。页面出现或回到前台重新检查，不建立后台轮询。

短信状态读取对应 agentID 已保存的 E2E 密钥；缺失、锁定及异常分别显示，已保存协商密钥不代表每条短信已成功解密。设备身份变化时重建状态视图，避免沿用其他设备的检查结果。

不修改通话路由、音频、配对密钥及 Relay 部署。安卓继续使用 140。
