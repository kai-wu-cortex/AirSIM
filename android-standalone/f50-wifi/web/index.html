酒店网页登录

让 iPhone 通过 F50 完成酒店认证。酒店的房号、验证码或登录资料仍在酒店页面填写。

iPhone 认证步骤
  1. 连接临时热点

    热点密码：

    提示无互联网时保持连接，再用 Safari 打开 ，输入本页管理密码。

  2. 开启这台 iPhone 的认证通道

    只有连接上述临时热点的设备才能启用。

  3. 设置临时热点的 HTTP 代理

    iPhone「设置 → Wi-Fi → 热点旁的信息按钮 → 配置代理 → 自动」，粘贴下方地址并保存。

  4. 在 Safari 完成酒店登录

    打开酒店认证入口

    若未跳转，可输入酒店提供的网址。完成后返回本页检查；不要忽略证书错误。

  5. 结束认证

    先在该临时热点的「配置代理」中改回「关闭」，再返回本页结束认证。F50 保持连接酒店 Wi-Fi，你可以让 iPhone 恢复使用 4G/5G。

认证窗口为 20 分钟；到期或酒店 Wi-Fi 断开会关闭。未完成时可断电重启，约 1 分钟后重新加入认证热点。酒店可能要求每次到店或租期到期后重新认证。

      仅保存会保留热点。点击“保存并重启”后，设备重启，再关闭热点连接此 Wi-Fi，系统启动满 1 分钟且就绪后开始连接；失败约 90 秒后恢复原热点。
